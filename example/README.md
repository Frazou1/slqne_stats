# SLQNE Hockey Stats

**Français** — Lit la page publique d'une ou de plusieurs équipes de hockey sur Spordle et publie dans Home Assistant, par MQTT, le classement, les statistiques des joueurs, le dernier match et le prochain match. Plusieurs équipes ou joueurs suivis peuvent être configurés. Voir l'onglet **Documentation** ou le [README du dépôt](https://github.com/Frazou1/slqne_stats#français).

**English** — Reads the public page of one or more hockey teams on Spordle and publishes the standings, player statistics, last game and next game to Home Assistant over MQTT. Several teams or tracked players can be configured. See the **Documentation** tab or the [repository README](https://github.com/Frazou1/slqne_stats#english).
